# Overview

This repository contains open access ISO files of digital collections, so anyone can download, explore and emulate them.

## State Library Virtual Tours (2001)

[Link to resource](./ISOs/virtual-tours/SLV2025-0-14/)

In 2001, during the redevelopment of the Library's Dome, State Library Victoria created State Library Virtual Tours, an interactive web experience on CD-R. Built with IPIX 3D photography, it let visitors move through reading rooms and corridors in panoramic views, including spaces they might not otherwise see.
 
In 2024, copies of the CD-R turned up in an office cupboard. The Library's Digital Preservation Lab imaged and examined the discs, and SLV LAB brought the tours back to life in a Windows 98 emulator hosted through AusEaaSI (Australian Emulation as a Service Infrastructure).
 
### Emulation requirements 

The tours rely on Java applets, which modern browsers no longer support. To experience them as they were designed, run the ISO files in an emulated Windows 98 environment.
